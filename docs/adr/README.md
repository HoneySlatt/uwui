# Decisions

An ADR records one decision: its context, the decision, the alternatives rejected, and its
consequences.

- Until uwui's code moves here, uwui's decisions are ADRs of SlimeEngine, in one numbering with the
  engine's: [SlimeEngine's index](https://github.com/HoneySlatt/SlimeEngine/blob/main/docs/adr/README.md).
- The interface's ADRs join this directory with uwui's code, at SlimeEngine's milestone M6d.11;
  how they are numbered here is decided at M6d.10.
